# 派工联系单

单文件网页小工具：填订单信息、选派去干活的师傅后自动核算每人到手金额，生成一张可下载/复制的派工图片，发群里不会被聊天记录刷走。

## 使用

直接用浏览器打开 `index.html` 即可，无需构建或安装依赖。

## 功能

- 客户信息：地址、电话、微信号、接单日期
- 订单信息：订单总价、需要人数、单号、备注（如顾客有洁癖等注意事项）
- 师傅名单常驻本地浏览器（localStorage），改一次长期用，团队人少（四五个）也方便维护
- 点名字选择本次派工的师傅，按订单总价自动均分到手金额，也可切换成自定义金额
- Canvas 绘制派工单样式，一键下载 PNG 或复制到剪贴板发微信
